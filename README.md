## Overview
A business intelligence dashboard built in Google Data Studio to monitor and analyze Cost of Goods Sold (COGS) for a buffet restaurant chain. The dashboard helps management track revenue, food costs, inventory waste, and operational performance across branches.

## Objectives
* Monitor COGS and profitability
* Track inventory waste and write-offs
* Analyze cost by buffet ticket and product category
* Compare branch performance
* Support operational decision-making

## Data Source
Internal ERP System

## Technology
- Google Data Studio (Looker Studio)
- Google sheet API

## Key Features
* Weekly and monthly COGS analysis
* Buffet ticket cost tracking
* Alacarte sales performance analysis
* Inventory waste monitoring
* Ingredient cost breakdown
* Branch comparison dashboard
* Consumption per customer analysis
